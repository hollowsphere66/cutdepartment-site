CUT DEPARTMENT WEBSITE — UPDATED WITH NO FIXED FORMAT ABOUT PAGE
================================================================

Contents: index.html (homepage), about.html (dedicated About page), styles.css,
script.js, and assets/ (homepage imagery and About-page vinyl image).

To preview: open index.html in your browser and click ABOUT.
To publish: upload the CONTENTS of this folder to your GitHub Pages repository
root (index.html and about.html must both be at the top level).

The homepage design is unchanged, except ABOUT now links to about.html.
The About page uses the approved heading "No Fixed Format" and the three
paragraphs of approved copy. It uses live, selectable text, not a screenshot,
so it adapts to phones and desktops. The photograph at the bottom is cropped
from the approved About design reference.

CONTACT on the homepage opens a small email panel. On the About page it opens
the user's email client. The address hello@cutdepartment.com is provisional;
confirm it works before publishing.

To configure social media destinations, edit SOCIAL_LINKS in script.js.
Unconfigured links are not clickable. The homepage desktop artwork includes
social icons as part of the approved image.

For GitHub Pages custom domain, configure the domain in repository Settings >
Pages and then update only the relevant website DNS records in Hover. Do NOT
change Google Workspace MX, SPF, DKIM, DMARC or verification records.

Note: Desktop homepage typography is part of the approved background image.
The About page is fully accessible live HTML and CSS.
